  1. AWSCreate an on-demand table shopnow-dev-items, keyed by tenantId + itemId. On-demand: pay per request.
  2. AWSWrite and read an item by its key IAM checks the app's role. The item is stored and read back by its key.
  3. AWSLock Terraform state (older setups) Table shopnow-dev-tflock, key LockID. Terraform 1.10+ can lock in S3 instead.
  4. AzureCreate a serverless Cosmos DB cosmos-shopnow-dev-7k2q: database appdb, container items, partition /tenantId.
  5. AzureThe app signs in with its identity id-shopnow-app has the Data Contributor role, so no account keys are needed.
  6. AzureLock state without a database The azurerm backend takes a lease on the state blob in tfstate (step 15).
  7. Google CloudCreate a Firestore database appdb in Native mode, in us-central1. There are no servers to size.
  8. Google CloudThe app uses its service account sa-shopnow-app has Cloud Datastore User, so it can read and write documents.
  9. Google CloudLock state in the bucket The gcs backend writes a lock file next to the state (step 15). No database.
