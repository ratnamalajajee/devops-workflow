  1. AWSCreate the disk in the VM's zone disk-shopnow-data01: gp3, 128 GiB, in us-east-1a. Other zones cannot use it.
  2. AWSAttach it, then format and mount it Attach to vm-shopnow-01 as /dev/sdf (it shows up as NVMe). Mount it at /data.
  3. AWSTake a snapshot Snapshots copy the disk. Data Lifecycle Manager or AWS Backup can schedule them.
  4. AzureCreate the disk in zone 1 disk-shopnow-data01: Premium SSD, 128 GiB, in zone 1 like vm-shopnow-01.
  5. AzureAttach it at LUN 0, then mount it Run command formats /dev/disk/azure/scsi1/lun0 and mounts it at /data.
  6. AzureTake an incremental snapshot Each incremental snapshot stores only what changed since the one before.
  7. Google CloudCreate a balanced persistent disk disk-shopnow-data01: pd-balanced, 128 GB, in us-central1-a like the VM.
  8. Google CloudAttach it as data01, then mount it Over SSH (through IAP), format /dev/disk/by-id/google-data01, mount at /data.
  9. Google CloudAdd a daily snapshot schedule sched-shopnow-daily snapshots the disk at 02:00 and keeps each one 14 days.
