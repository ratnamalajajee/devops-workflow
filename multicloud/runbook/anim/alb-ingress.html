  1. AWSYou apply the Ingress Ingress web, class alb, internet-facing, target type ip, to service web.
  2. AWSThe controller sees it and builds an ALB It acts as role-shopnow-lbc (Pod Identity) and creates a new ALB.
  3. AWSThe ALB sends users to the pods Target type ip: traffic goes straight to the web pod IPs.
  4. AzureYou apply the Ingress The same Ingress web, with class azure-application-gateway.
  5. AzureAGIC programs the gateway It takes over all of agw-shopnow-dev, so the VM rule from step 21 goes away.
  6. AzureThe gateway sends users to the pods agw-shopnow-dev sends traffic straight to the web pod IPs.
  7. Google CloudYou apply the Ingress Class gce, static IP ip-shopnow-gke, managed certificate web-cert.
  8. Google CloudGKE builds a global load balancer The built-in controller needs no setup. The LB takes 5 to 10 minutes.
  9. Google CloudThe load balancer sends users to pods Users reach ip-shopnow-gke. The cert turns Active after DNS (step 23).
