  1. AWSSign in through IAM Identity Center Run aws sso login, not the root user, and choose the shopnow-dev account.
  2. AWSPick the region, tag every resource us-east-1. AWS has no resource group box, so tag app=shopnow, env=dev.
  3. AWSAdd the log group, then build on it /shopnow/dev/platform keeps logs 30 days. Later steps use this setup.
  4. AzureSign in and pick the subscription Run az login, check the tenant, then az account set to your subscription.
  5. AzureRegister the resource providers Microsoft.Network, Compute, KeyVault and the rest must show Registered.
  6. AzureCreate the resource group rg-shopnow-dev Region East US 2, tags env=dev, app=shopnow, owner=sre.
  7. AzureCreate the Log Analytics workspace law-shopnow-dev, same group. AKS (step 13) and Functions (step 14) use it.
  8. Google CloudSign in and create the project Run gcloud auth login, then create shopnow-dev (ID shopnow-dev-7k2q).
  9. Google CloudLink billing and set the region Link a billing account. Set region us-central1, zone us-central1-a.
  10. Google CloudEnable the APIs; logging is already on Compute Engine, Kubernetes Engine, Cloud KMS, Secret Manager and the rest.
