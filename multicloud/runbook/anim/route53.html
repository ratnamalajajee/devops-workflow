  1. AWSThe browser asks for app.shopnow.example.com The registrar points to the zone's four NS. The resolver asks Route 53.
  2. AWSThe zone answers with the ALB Alias A record app points at alb-shopnow-dev. The browser connects there.
  3. AWSA private zone answers only inside internal.shopnow.example.com works only in vpc-shopnow-dev. Outside: no answer.
  4. AzureThe browser asks for app.shopnow.example.com The registrar points to the zone's four Azure DNS name servers.
  5. AzureThe zone answers with the gateway IP Alias record set app points at pip-shopnow-appgw and follows it if it changes.
  6. AzureA private zone answers only inside internal.shopnow.example.com is linked to vnet-shopnow-dev. VMs auto-register.
  7. Google CloudThe browser asks for app.shopnow.example.com The registrar points to Cloud DNS name servers. DNSSEC is on for this zone.
  8. Google CloudThe zone answers with the LB IP A record app holds the ip-shopnow-lb address. Cloud DNS has no alias type.
  9. Google CloudA private zone answers only inside zone-shopnow-private answers only in vpc-shopnow-dev. Outside: no answer.
