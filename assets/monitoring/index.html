Monitoring stack files

The values files, IAM policies and dashboards used in the runbook. Follow the runbook for the order and the commands; it explains every setting.

Before you install, replace every value marked CHANGE or REPLACE_WITH_…, and the cluster name my-eks-qa. Passwords and SMTP credentials never go in these files; the runbook creates them as Kubernetes Secrets.

Download everything

bash
MON_URL=https://devops-workflow.pages.dev/assets/monitoring
mkdir -p ~/monitoring/dashboards && cd ~/monitoring
for f in prometheus-values.yaml grafana-values.yaml loki-values.yaml fluent-bit-values.yaml \
         jaeger-values.yaml jaeger-badger-pvc.yaml sql-exporter-values.yaml \
         grafana-cloudwatch-trust-policy.json grafana-cloudwatch-policy.json; do
  curl -fsSLO "$MON_URL/$f"
done
for f in cluster-logs-loki.json aurora-long-running-queries.json; do
  curl -fsSL -o "dashboards/$f" "$MON_URL/dashboards/$f"
done
grep -n "CHANGE\|REPLACE_WITH\|my-eks-qa" *.yaml      # the values you must set
